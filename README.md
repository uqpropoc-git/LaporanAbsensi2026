# LaporanAbsensi2026
Halaman Interaktif Rekapitulasi Absensi Karyawan PT Multi Sarana Avindo Periode Januari - November 2026

Fitur Interaktif Utama pada Halaman HTML:

    Filter Divisi & Rentang Waktu: Atasan dapat menyaring data berdasarkan divisi (Office, OB & Driver, CHF/Pengapalan, Keamanan Pos Simpang KTA) serta rentang kuartal (Q1–Q4) atau bulan spesifik—seluruh kartu KPI dan grafik akan otomatis menghitung ulang.

    Isolasi Kategori (Hanya Ketidakhadiran): Tersedia tombol cepat untuk menyembunyikan batang Hadir (H) sehingga atasan bisa langsung membandingkan sebaran Sakit (S), Cuti (C), Ijin (I), dan Tugas Kapal (TK) secara jernih.

    Klik-untuk-Inspeksi (Drill-Down Karyawan): Mengklik batang atau baris nama karyawan mana pun akan langsung menampilkan grafik batang bulanan (Januari–Nopember) dan matriks angka rincian karyawan tersebut di panel sebelah kanan.

    Siap Cetak / Simpan PDF: Dilengkapi tombol cetak yang otomatis menyembunyikan elemen kontrol agar rapi saat dicetak atau diekspor ke PDF.
